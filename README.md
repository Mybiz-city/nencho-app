# メーティス 年末調整アプリ（Google Apps Script 版）

従業員がスマホで年末調整の内容を入力し、控除証明書を写真で送り、日本ICS（給与マスター表形式・タイプ6）に取り込むCSVを作るアプリです。
画面も保存先もすべて Google の中（Apps Script ＋ work@metis.tax のドライブ）で動きます。サーバーの管理はありません。

- `gas/` … 年末調整アプリ本体（Apps Script に貼り付けるファイル）
- `test/` … ローカルで動かす開発用（Node）
- `furusato/` … ふるさと納税 限度額の目安（さくらサーバーのPHP。下記）
- `index.php` `api.php` `admin/` `company/` `lib/` … 以前のさくらサーバー版の年末調整アプリ（使いません。参考用に残しています）

## 画面

| 画面 | URL | 入り方 |
|---|---|---|
| 従業員 | `…/exec` | 登録コード（10桁）＋初回番号（6桁）。2回目以降はそのスマホで自動 |
| 会社（経営者） | `…/exec?p=company&c=顧問先コード&k=合言葉` | 事務所画面で発行したURL（90日で期限切れ） |
| 事務所 | `…/exec?p=admin` | パスワード＋認証アプリの6桁 |

## 初回の導入（1回だけ）

1. work@metis.tax で https://script.google.com を開き、「新しいプロジェクト」
2. 左の「ファイル」で、`gas/` の中の各ファイルを同じ名前で作り、中身を貼り付ける
   - `Code.gs` `Common.gs` `Judge.gs` `Ics.gs` `Emp.gs` `Admin.gs` `Company.gs` `Claude.gs` `Zip.gs` `Xlsx.gs` `Update.gs`（スクリプト）
   - `Emp.html` `Admin.html` `Company.html`（HTML）
   - `appsscript.json`（左の歯車「プロジェクトの設定」→「appsscript.json マニフェスト ファイルをエディタで表示する」にチェックを入れると出てくる）
3. エディタ上部で関数 `初期設定` を選び「実行」→ 権限を許可 → 実行ログに、事務所パスワードと2段階認証の秘密の文字列が1回だけ出る。控える
4. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」→ 実行ユーザー「自分」、アクセス「全員」→ デプロイ。出てきたURLがアプリのURL
5. 事務所画面（`URL?p=admin`）に入り、「設定・取り込み」→ AI読み取りの鍵（Anthropic のAPIキー）を入れる
6. 更新ボタンを使うために、https://script.google.com/home/usersettings で「Google Apps Script API」をオンにする

## 更新

事務所画面の右上「アプリを更新」で、この GitHub の `gas/` の最新版を取り込み、新しい版として配備し直します。
更新のたびに、変更点の日本語の説明（コミットメッセージ）を添えます。

## データの置き場所

ドライブの「年調アプリデータ」フォルダ：`顧問先コード／年／個人コード／`（`answers.json` 本人の入力、`prev.json` 前年CSVの内容、`roster.json` 在籍と初回番号、`photos/` 写真、`submitted.json` 提出時の控え）。
ルートに `_clients.json`（顧問先名）、`_company_keys.json`（会社用URL）、`_devices.json`（従業員のスマホの合鍵）、`_audit_YYYYMM.log`（記録）。
5年保管し、それより古い年は事務所画面から削除します。

## ふるさと納税 限度額の目安（furusato/）

| ファイル | 役割 |
|---|---|
| furusato/index.html | スマホ向けの1画面1問。入口で「給与」「事業」を選ぶ。給与：年収→家族→保険料→結果。事業：売上・経費（または推移損益の写真）→見込み→消費税→家族→保険料→結果 |
| furusato/calc.js | 限度額の計算部品。画面に触らない純粋な計算 |
| furusato/ocr.php | 推移損益（推移試算表）の写真・PDF → Claude API で月別所得を読む。確定申告書の読み取りは廃止（画像提供の心理的抵抗が強いため）。ファイルは残さない。IPごとに1時間30回まで |

- URL：`https://metis.tax/furusato/`（/nencho/furusato/ へ転送）。年末調整アプリとの連携は廃止（個人情報をサーバーに置かない方針。計算だけで、入力は保存しない）
- 給与収入2,000万円以上（または合計所得1,805万円以上）の人には、目安を使わず税理士に依頼するよう案内する
- すべて概算。給与天引きの社会保険料は年収×15.5%を初期値にして本人が直す。保険料がAI読み取り前なら本人が概算で入れる
- 結果は保存しない（目安のため）
